    Wygląd

    Inspiracja: szablon Protocol (Tailwind UI). Wybierz preset lub własny kolor tła strony.

    Fashion AI — OpenAI connector

    Klucze API dla stylisty AI w aplikacji (propozycje outfitów z szafy). Ustawienia są tylko tutaj — end user w panelu ich nie widzi. Aktywny klucz jest używany przez Laravel przy sugestiach. Możesz zostawić logikę w lokalnym system promptcie (Chat) albo podpiąć Prompt/Agent z OpenAI Dashboard (Agent) — wtedy aplikacja wysyła tylko dane Prima (garderoba + okazja).

    Tryb wywołania

    W trybie Agent logikę (instrukcje, narzędzia, schemat JSON) trzymasz w OpenAI. Aplikacja wysyła tylko JSON: persona, garderoba, okazja.

    Skopiuj ID z platform.openai.com/prompts (lub Agent Builder → Prompt). Laravel wywoła POST /v1/responses z tym ID.

    OpenAI — instrukcja (system prompt)

    Podgląd tego, co Laravel wysyła do OpenAI jako role=system przy sugestiach stylisty. Możesz edytować i zapisać — aktywny tekst jest brany z tego miejsca przy każdym requestcie.
