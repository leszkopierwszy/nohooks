# Jak otworzyć vault

1. Zainstaluj [Obsidian](https://obsidian.md).
2. **Open folder as vault**.
3. Wskaż katalog:

```
docs/vault
```

pełna ścieżka przykładowa:

```
/Users/bart/code/nohooks copy/docs/vault
```

4. Start od notatki [[Home]].

## Graph

Włącz **Graph view** — kolory grup po tagach `#database`, `#component`, `#flow` (ustawione w `.obsidian/graph.json`).

## Sync z repo

Vault leży w git. Edytuj tu albo w `docs/*.md` — to osobne kopie; vault ma wiki-linki Obsidiana.
